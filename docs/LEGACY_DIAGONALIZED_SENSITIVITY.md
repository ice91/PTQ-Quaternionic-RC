# Legacy analysis firewall

## Classification

Archived radius-level WAIC / PSIS-LOO constructions in this repository are:

`LEGACY_DIAGONALIZED_SENSITIVITY`

## Meaning

- Historical Bayesian predictive scores used **diagonalized per-radius** likelihood contributions.
- Primary manuscript fits / MLE accounting use **full within-galaxy covariance** \(C_g\).
- Multi-seed WAIC tables are **reproducibility records only**.
- These scores are **not** the canonical headline theory-ranking layer for the current Frontiers / Version-5 manuscript.

## Retention policy

Do **not** delete historical WAIC/LOO artifacts merely because interpretation changed.
Keep them marked as legacy sensitivity.
